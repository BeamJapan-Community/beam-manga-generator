# BEAM Manga dApp Generator

**漫画を、BEAM Walletで読めるdAppに。**

BEAM Manga dApp Generatorは、漫画の画像ファイルやPDFから、**BEAM Desktop Walletで閲覧できる漫画dApp（`.dapp`ファイル）を作成する無料のWebツール**です。

プログラミングの知識やユーザー登録は必要ありません。

漫画クリエイターが自分の作品をdAppとして配布し、読者からBEAMによるチップを直接受け取ることをサポートします。

---

## 主な機能

- **漫画dAppの生成**：JPG・PNG・WebP・PDFファイルに対応
- **PDF自動変換**：PDFの各ページを画像に自動変換
- **ページ送り機能**：漫画を1ページずつ表示
- **ズーム機能**：拡大・縮小・画面サイズに合わせた表示
- **画像圧縮機能**：WebP形式への変換でファイルサイズを削減
- **チップ機能**：作者のBEAMアドレスを表示し、直接送金をサポート
- **ブラウザ内処理**：漫画データを外部サーバーにアップロードせずに生成

**<u>無料・ユーザー登録不要・プログラミング不要</u>**

---

## 使い方

### 1. ジェネレーターを開く

GitHub Pagesで公開されているBEAM Manga dApp Generatorをブラウザで開きます。

### 2. 漫画ファイルを読み込む

JPG・PNG・WebP画像、またはPDFファイルを選択します。

PDFを選択した場合は、各ページが自動的に画像へ変換されます。

### 3. 作品情報を入力する

- 漫画のタイトル
- 作者名
- 作者のBEAM Public Offline Address

チップを受け取る場合は、**必ず自分のBEAM Walletで受取アドレスを確認してください。**

### 4. 画像を調整する

必要に応じてページ順や画像圧縮の設定を調整します。

### 5. dAppを生成する

「.dappファイルを生成」をクリックします。

生成が完了すると、ダウンロードリンクが表示されます。

リンクをクリックして`.dapp`ファイルを保存してください。

### 6. BEAM Walletで閲覧する

生成した`.dapp`ファイルをBEAM Desktop Walletで開きます。

漫画のページ送りやズーム、作者情報の表示を確認してください。

## BEAMによるクリエイター支援

BEAM Manga dApp Generatorでは、作品に作者のBEAMアドレスを登録できます。

読者は作品を楽しんだ後、作者のアドレスをコピーし、BEAM Walletの通常の送金機能を利用して直接チップを送ることができます。

**特徴**

- 作者と読者の間で直接送金
- ジェネレーターによる送金手数料の徴収なし
- スマートコントラクト不要
- 第三者の決済サービスとの連携不要

<u>本ツール自体は送金処理を実行しません。</u>

チップの送金は、読者自身がBEAM Walletで操作します。通常のネットワーク手数料が発生する場合があります。

## プライバシーについて

**漫画ファイルはブラウザ内で処理されます。**

漫画画像やPDFをジェネレーター運営者のサーバーへアップロードする必要はありません。

ただし、PDFの変換には外部ライブラリを利用するため、インターネット接続が必要です。

また、生成したdAppには漫画画像や登録した作者情報が含まれます。

**<u>公開・配布して問題のない情報だけを登録してください。</u>**

## 注意事項

1. **BEAMアドレスの確認**

   作者のBEAM Public Offline Addressは、必ず本人が確認してください。入力チェックはアドレスの有効性を完全に保証するものではありません。

2. **著作権について**

   自分が著作権を保有する作品、または配布許可を得た作品のみを使用してください。

3. **コンテンツの保護について**

   生成したdAppにはDRMやコピー防止機能はありません。漫画画像を第三者が取り出せる可能性があります。

4. **大容量ファイルについて**

   大容量のPDFや大量の画像を変換すると、ブラウザのメモリ使用量が増え、処理に時間がかかる場合があります。

5. **動作保証について**

   本ツールは無保証で提供されます。生成したdAppは配布前に必ず動作確認してください。
