BEAM Manga dApp Generator

漫画を、BEAM Walletで読めるdAppに。

BEAM Manga dApp Generatorは、漫画の画像ファイルやPDFから、BEAM Desktop Walletで閲覧できる漫画dApp（.dappファイル）を作成する無料のWebツールです。

プログラミングの知識やユーザー登録は必要ありません。

主な機能

漫画dAppの生成：JPG・PNG・WebP・PDFに対応

PDF自動変換：PDFの各ページを画像に変換

ページ送り：1ページずつ表示する漫画ビューワー

ズーム機能：拡大・縮小・画面サイズに合わせた表示

画像圧縮：WebP形式への変換によるファイルサイズ削減

チップ機能：作者のBEAMアドレスを表示し、読者からの直接送金をサポート

ブラウザ内処理：漫画データをサーバーにアップロードせずに生成

使い方

BEAM Manga dApp GeneratorのWebサイトを開きます。

漫画のタイトルと作者名を入力します。

JPG・PNG・WebP画像、またはPDFを読み込みます。

必要に応じて画像の圧縮設定やページ順を調整します。

チップを受け取る場合は、作者のBEAM Public Offline Addressを入力します。

「.dappファイルを生成」をクリックします。

生成完了後、表示されたダウンロードリンクから.dappファイルを保存します。

生成したファイルをBEAM Desktop Walletで開いて動作を確認します。

BEAMによるクリエイター支援

作成した漫画dAppには、作者のBEAMアドレスを登録できます。

読者はアドレスをコピーし、BEAM Walletの通常の送金機能を使って作者に直接チップを送れます。

このツール自体は送金処理を行いません。また、スマートコントラクトによる決済機能も使用しません。

プライバシーについて

漫画画像やPDFはブラウザ内で処理され、生成のために運営者のサーバーへアップロードされることはありません。

ただし、PDF変換用の外部ライブラリを読み込むため、インターネット接続が必要です。

また、公開・配布する.dappには漫画画像や登録した作者情報が含まれます。公開して問題のない情報だけを登録してください。

動作環境

Google Chrome、Microsoft Edgeなどのモダンブラウザ

BEAM Desktop Wallet（生成したdAppの閲覧用）

PDF変換時はインターネット接続が必要

注意事項

BEAM Public Offline Addressは、必ず作者自身で正しいことを確認してください。

本ツールはBEAMアドレスの有効性を完全に保証するものではありません。

生成されたdAppにはDRMやコピー防止機能はありません。

大容量PDFの変換には時間とメモリが必要になる場合があります。

自分が権利を保有する、または配布許可を得た漫画を使用してください。

本ツールは無保証で提供されます。
